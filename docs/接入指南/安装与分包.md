# 安装与分包

适用于 `IFLYADLib 6.5.0`。[返回 SDK 首页](../../README.md)。完整方法签名以所安装版本的公开头为准。

### CocoaPods

使用 CocoaPods 官方 trunk 安装固定版本。Podspec 的版本清单由 CocoaPods 管理，二进制仍由 TOS 分发。

```ruby
source 'https://cdn.cocoapods.org/'
platform :ios, '11.0'

target 'YourApp' do
  use_frameworks!
  # 默认安装 Full，包含开屏、Banner、插屏、自渲染信息流和激励视频五种广告。
  pod 'IFLYADLib', '6.5.0'
end
```

然后执行：

```bash
pod install
open YourApp.xcworkspace
```

上面的裸写法等价于选择 `Full`，会安装全部五种广告。如果只需要部分能力，请将 `pod` 行替换为对应 subspec；同一个 target 不要同时写裸 `IFLYADLib` 和其他 subspec：

```ruby
# 只接入开屏：Core 和 VideoUI 会自动带入
pod 'IFLYADLib/Splash', '6.5.0'

# 只接入 Banner + 自渲染信息流：两个格式共用一份 Core
pod 'IFLYADLib/Banner', '6.5.0'
pod 'IFLYADLib/NativeFeed', '6.5.0'

# 只接入基础 Core（不包含任何广告格式）
pod 'IFLYADLib/Core', '6.5.0'

# 显式写 Full，和最上面的裸写法等价
pod 'IFLYADLib/Full', '6.5.0'
```

选择 `Splash`、`Interstitial` 或 `Reward` 时，`Core`、`VideoUI` 及所需资源会由依赖关系自动安装；`Banner` 和 `NativeFeed` 只自动依赖 `Core`。替换 Podfile 后重新执行 `pod install`，再打开生成的 `.xcworkspace`。

### Swift Package Manager（GitHub 包源，TOS 二进制）

在 Xcode 中选择 **File > Add Package Dependencies…**，输入公开仓地址：

`https://github.com/LJMcarryu/IFLYADLib_iOS.git`

版本选择 **Exact Version** `6.5.0`。仓库中的 `Package.swift` 负责声明产品、资源和校验值；实际 XCFramework 由 TOS 地址提供。

SwiftPM 接入时，在最终 App target 的 **Other Linker Flags** 中保留 `$(inherited)` 并添加：

```text
-ObjC
```

### 下载与手动集成

[6.5.0 发布记录](https://download-adsdk.voiceads.cn/ios_sdk/6.5.0/general/fast-release-record.json) 的完整包为 `IFLYADLib-modelA-6.5.0.zip`；各模块另有独立的 XCFramework 压缩包。文件摘要见同版 `checksums.txt`。首次接入建议使用 CocoaPods；需要自行管理模块时，按下面的 TOS 手动集成步骤处理依赖、公开头和资源。

手动接入须把所选格式及其依赖一起加入 App target，Embed 选择 **Do Not Embed**：

| 使用的格式 | 必须链接的 XCFramework |
| --- | --- |
| Banner | `IFLYAdCore`、`IFLYAdBanner` |
| 自渲染信息流 | `IFLYAdCore`、`IFLYAdNativeFeed` |
| 开屏 | `IFLYAdCore`、`IFLYAdVideoUI`、`IFLYAdSplash` |
| 插屏 | `IFLYAdCore`、`IFLYAdVideoUI`、`IFLYAdInterstitial` |
| 激励视频 | `IFLYAdCore`、`IFLYAdVideoUI`、`IFLYAdReward` |

多个格式共用的模块只链接一次。在 App target 的 **Link Binary With Libraries** 中添加 `AdSupport.framework`，并将 `AppTrackingTransparency.framework` 设置为 **Optional**，以兼容 iOS 14 以下系统。最终 App 添加 `$(inherited) -ObjC`；这些模块包含带 modulemap 的静态 framework；直接添加 XCFramework，设置 **Do Not Embed**，无需旧版自定义头搜索路径。Swift 使用 `import IFLYAdCore` 和对应格式模块。

完整压缩包的 `resources/Core`、`resources/VideoUI`、`resources/Reward` 是资源文件目录。手动接入可从本仓同一版本 Tag 的 `spm` 目录取得已整理的资源包，加入 App 的 **Copy Bundle Resources**：所有格式需要 `spm/Core/IFLYADLibCoreResources.bundle`；开屏、插屏、激励另需 `spm/VideoUI/IFLYADLibVideoUIResources.bundle`；激励再加 `spm/Reward/IFLYADLibRewardResources.bundle`。另将 `spm/Core/Resources/PrivacyInfo.xcprivacy` 单独加入 **Copy Bundle Resources**（完整压缩包中的对应文件为 `resources/Core/PrivacyInfo.xcprivacy`）；该隐私清单不在 Core 资源 bundle 内。不要只加入单个格式的二进制 zip，也不要混用不同版本的模块和资源。

## 导入与共存

Objective-C 导入 Core 伞头和对应格式模块头，完整对应表见[迁移指南](Swift模块接入与头路径迁移.md)；SwiftPM 选择所需格式 product，由其引入模块依赖。不同格式共用的模块只链接一次。通用版与使用相同 `IFLY*` 符号的优酷定制版不能同时链接；其他渠道也不构成共存支持承诺。

本版完整包：[下载 IFLYADLib-modelA-6.5.0.zip](https://download-adsdk.voiceads.cn/ios_sdk/6.5.0/general/IFLYADLib-modelA-6.5.0.zip)。
